# StandoffShop

Независимый магазин цифровых товаров и услуг для игроков Standoff 2. Не аффилирован с разработчиками игры.

## Локальный запуск

Требуются Node.js 20+, npm и Docker.

1. Скопируйте `.env.example` в `.env`.
2. Установите **уникальный случайный** `SESSION_SECRET` длиной от 32 символов. Не используйте пример из репозитория.
3. `docker compose up -d`
4. `npm install`
5. `npx prisma generate`
6. `npm run db:push`
7. `npm run dev` — откройте http://localhost:3000

Для наполнения каталога: `npx prisma studio`. Создайте категории и товары, задайте `status=ACTIVE`. Цена хранится в копейках.

## v0.2.0 — Shopping & Accounts

- Клиентская корзина в localStorage: добавление, изменение количества, удаление, предварительная сумма.
- Оформление неоплаченного заказа с email, валидацией и серверным пересчётом стоимости по активным товарам.
- Регистрация и вход с паролями scrypt, подписанной HttpOnly cookie, выход.
- История до 50 последних заказов, созданных во время авторизованной сессии. Гостевые заказы к профилю автоматически не привязываются.
- Роль `ADMIN` и начальная обзорная панель `/admin`; сводка доступна через `/api/admin/overview`.
- Платёжный адаптер остался отключённым. Подтверждение оплаты браузером невозможно.

## API

- `POST /api/auth/register` — `{email,password}` (пароль от 12 символов).
- `POST /api/auth/login` — `{email,password}`.
- `POST /api/auth/logout` — завершить сессию.
- `GET /api/me/orders` — заказы текущего пользователя.
- `GET /api/admin/overview` — статистика для роли ADMIN.
- `POST /api/orders` — `{email,items:[{productId,quantity}]}`.

Все новые аккаунты получают роль CUSTOMER. Для локального тестирования роли ADMIN можно изменить поле `role` у тестового пользователя через Prisma Studio. Не выдавайте роль через публичный API.

## Известные ограничения

**Это промежуточная версия, не готовая к публичному запуску.** Нет rate limiting, защиты от перебора паролей, подтверждения email, сброса пароля, полноценного CRUD админки, механизма идемпотентности создания заказа, контроля остатков и реального эквайринга. Нет подтверждённого прогона CI/сборки. Не открывайте авторизацию и заказы в production до завершения мер защиты и тестирования.

Перед продажами проверьте правила игры, юридические документы и допустимость товаров.
