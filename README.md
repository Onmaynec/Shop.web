# StandoffShop

Интернет-магазин цифровых товаров и услуг для игроков Standoff 2. Независимый проект, не аффилированный с разработчиками игры.

## Локальный запуск

Требуются Node.js 20+, npm и Docker.

1. Скопировать `.env.example` в `.env`.
2. Запустить PostgreSQL: `docker compose up -d`.
3. Установить зависимости: `npm install`.
4. Сгенерировать клиент: `npx prisma generate`.
5. Применить схему: `npm run db:push`.
6. Запустить сайт: `npm run dev`.
7. Открыть http://localhost:3000.

Каталог изначально пуст. Создавайте категории и товары через `npx prisma studio`. Для показа товара установите `status=ACTIVE`. Цены хранятся в копейках.

## v0.1.0 — Foundation

- Next.js, TypeScript, адаптивная главная, каталог и страницы товаров.
- PostgreSQL, Prisma: категории, товары, позиции заказа, заказы и попытки оплаты.
- `POST /api/orders`: JSON `{"email":"buyer@example.com","items":[{"productId":"...","quantity":1}]}`. Сервер валидирует запрос, проверяет активность товаров, пересчитывает стоимость и сохраняет снимок цен.
- Интерфейс `PaymentProvider` и заглушка `UnconfiguredPaymentProvider` без реального эквайринга.
- Docker Compose для локальной PostgreSQL.

## Ограничения

**Это foundation, не production-релиз.** Нет корзины, UI оформления, аккаунтов, админки, вебхуков, защиты от спама, идемпотентности запросов, контроля остатков и автоматической выдачи. Не открывайте API заказов публично до добавления защиты. Браузер не может подтверждать оплату. Реальные платежи отключены.

Перед запуском продаж необходимо проверить правила Standoff 2, юридические условия и безопасность платежной интеграции.
