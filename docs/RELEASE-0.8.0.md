# StandoffShop v0.8.0 — Order Management 2.0

## Управление заказами

- Добавлена история заказов (`OrderActivity`): создание, смена статуса, оплата/возврат, задачи, комментарии и выдача материалов.
- Отдельная очередь исполнения `/admin/queue`: задачи формируются по позициям заказа после проверенного платежа.
- Администратор может взять задачу, освободить или переключить её статус: OPEN, IN_PROGRESS, BLOCKED, DONE.
- Завершить заказ можно только после завершения всех задач и подтверждения оплаты.
- В карточке заказа доступны внутренние заметки и сообщения покупателю.
- Все значимые действия записываются в аудите.

## Для покупателя

- Добавлена история конкретного заказа `/account/orders/<id>`.
- Добавлен раздел уведомлений `/account/notifications`: новые сообщения, смена статуса, публикация или отзыв файла.
- Уведомления работают внутри сайта; внешняя почтовая отправка не подключена.
- Внутренние заметки администраторов покупателю не показываются.

## Цифровая выдача

- Добавлена загрузка приватных PDF/PNG/JPEG/TXT до 4 МиБ, вне публичной директории.
- Материалы публикуются вручную только после выполнения всех задач и проверки оплаты.
- Скачивание проходит проверку владельца заказа, статуса, подтверждения платежа, доступности файла и SHA-256.
- На возврате скачивание закрывается, файлы помечаются отозванными.
- Гостевые заказы не получают приватный доступ по одному только совпадению email.

## База данных и эксплуатация

- Новая миграция `20261114080000_order_management` без удаления старых таблиц.
- Для прежних заказов создаётся начальная запись истории.
- Приватные материалы нужно включить в отдельное резервное копирование наряду с PostgreSQL.
- Добавлены модульные проверки и интеграционные сценарии работы с заказами, оплатой, доступом и возвратами.

## Ограничения

Реальный эквайринг **не подключён**. Sandbox предназначен только для локальной разработки и в production отключён. Нет SMTP, автоматического исполнения, публичных гостевых ссылок, продакшен-S3, MFA и антивирусной обработки пользовательских документов. До коммерческой эксплуатации необходима отдельная инфраструктурная и security-проверка.
