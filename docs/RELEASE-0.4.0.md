# StandoffShop v0.4.0 — Payment Readiness

## Заказы

- Добавлены `idempotencyKeyHash` и `requestHash` для защиты от повторного создания заказов.
- `POST /api/orders` требует `Idempotency-Key`, проверяет Origin и JSON, суммирует одинаковые товары и проверяет актуальные цены через PostgreSQL.
- Ключи хранятся хешированными. Повтор запроса возвращает тот же ID заказа; повтор ключа с другими товарами отклоняется.
- Корзина сохраняет ключ до успешного ответа и показывает результат оформления с итоговой ценой из сервера.

## Платежи

- Выделен типизированный `PaymentProvider`.
- Реализованы проверка HMAC-SHA256, допустимого времени webhook, строгой схемы события и проверка суммы/валюты.
- Добавлены таблицы `PaymentAttempt` и `PaymentEvent` с уникальностью событий по провайдеру и ID.
- Событие, платёжная попытка и заказ обновляются в транзакции. Повторное webhook-событие безопасно.
- Реализован полный возврат тестового платежа.
- Добавлены локальные инструменты тестовой оплаты и возврата в админке (только ADMIN + локальный dev).
- В production sandbox принудительно выключен. **Реальный эквайринг отсутствует**.

## Тестирование

- Модульные проверки подписи, протухших webhook, формата события и идемпотентности.
- Проверка production-приложения с PostgreSQL: создание заказа, повтор, конфликт ключа, защита admin и отключение sandbox.
- Отдельный интеграционный тест локального sandbox: учёт платежа, replay, неверная подпись, несоответствие суммы и полный возврат.

## Установка

```cmd
docker compose up -d
npm install
npx prisma validate
npx prisma generate
npm run db:push
npm run dev
```

После обновления проект сохраняет существующие записи PostgreSQL. Обязательно используйте актуальный `.env` с корректными `DATABASE_URL` и `SESSION_SECRET`.

Для локального тестирования платежей укажите `PAYMENT_SANDBOX_ENABLED=true` и новый отдельный секрет `PAYMENT_SANDBOX_SECRET` длиной от 32 символов. Запуск без sandbox не требует дополнительной настройки.

Инструкция по платежному контуру: [PAYMENTS.md](PAYMENTS.md).

## Что ещё не готово

Подключение реального платёжного провайдера, автоисполнение заказов, частичные возвраты, продакшен-аудит, юридические документы и антивзломная защита. Публиковать магазин для реальных продаж пока нельзя.
