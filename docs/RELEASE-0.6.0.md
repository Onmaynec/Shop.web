# StandoffShop v0.6.0 — Security & Stability

## Авторизация

- Заменены stateless cookies на случайные серверные сессии с хранением HMAC-хеша в PostgreSQL.
- Добавлены истечение срока, отзыв, список активных сессий, завершение выбранной/остальных/всех сессий.
- Реализована смена пароля с проверкой текущего пароля и немедленным отзывом всех сессий.
- Старые сессии из v0.5.0 после обновления требуют повторной авторизации.

## Ограничение запросов

- Создана таблица `RateLimitBucket` и атомарные счётчики PostgreSQL.
- Введены ограничения на попытки входа, регистрацию, оформление заказов, изменение пароля и admin API.
- Ответы при превышении лимита: HTTP 429 и `Retry-After`.
- Доверенные сетевые IP-заголовки выключены по умолчанию.
- Повторы заказа с тем же ключом идемпотентности не расходуют лимит новых заказов.

## Аудит администрирования

- Добавлена `AuditLog` с отметкой времени и ID администратора.
- Создание, редактирование и архивирование товаров, изменение категорий, статусов заказов и тестовые платежи пишутся в журнал.
- Аудит записи входит в транзакцию изменения состояния, чтобы не сообщать об успехе без следа в журнале.
- Добавлен раздел `/admin/audit`.

## Серверная безопасность

- Проверка Origin и JSON для авторизации и смены пароля.
- Ограничение размера тела запросов и дополнительные заголовки безопасности.
- Текущие полномочия и сессии проверяются в БД; роль администратора не передаётся в cookie как источник истины.

## Эксплуатация

- Добавлены `prisma/migrations`: baseline схемы v0.5.0 и отдельная миграция v0.6.0.
- PowerShell-сценарий резервного копирования PostgreSQL с проверкой архива.
- Инструкция обновления существующей базы без удаления данных.
- Скрипт очистки давно истёкших сессий и rate-limit записей.
- Версия Next.js зафиксирована на исправленном maintenance-выпуске 15.5.29.

## Тестирование

- Модульные проверки паролей, fingerprint и доверенных IP-заголовков.
- HTTP-тесты регистрации, сессий, отзыва, смены пароля, блокировки входа, Origin и аудит-операций.
- CI с PostgreSQL, Prisma migrations, TypeScript, unit tests, production сборкой, smoke и sandbox.
- Visual UI проверки сохранены для чёрно-белого дизайна v0.5.0.

## Ограничения

Нет подключения реального эквайринга, MFA, email-верификации и подтверждённого восстановления пароля: отправка писем требует отдельного провайдера. Недостающие меры до публичного запуска перечислены в [SECURITY.md](SECURITY.md).

**Для обновления существующей БД сначала ознакомьтесь с [DATABASE.md](DATABASE.md) и сделайте резервную копию.**

## Зависимости и воспроизводимость

- Зафиксирован Next.js 15.5.29 из поддерживаемой линии с исправлениями безопасности.
- Zod обновлён до актуальной 4.6.7; API и тесты проверены на совместимость.
- Исправленные PostCSS 8.5.32 и deepmerge-ts 8.0.2 используются через npm overrides.
- Prisma CLI перенесён в devDependencies.
- Добавлен `package-lock.json`, GitHub Actions устанавливает зависимости через `npm ci`.
- В CI добавлены `npm audit --omit=dev --audit-level=high` и проверка отсутствия расхождений между SQL-миграциями и Prisma Schema.

**Важно:** прохождение автоматической проверки зависимостей не заменяет аудит инфраструктуры и приложения. Версия остаётся предназначенной для локальной проверки и дальнейшей подготовки к production.
