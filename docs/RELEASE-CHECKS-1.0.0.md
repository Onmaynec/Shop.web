## Обновление с 0.9.0-rc.1

1. Остановить Next.js, сохранить PostgreSQL (дополнительно проверить восстановление на тестовой базе), `.env`, `data/media` и `data/deliveries`.
2. Обновить файлы в той же папке Docker Compose-проекта. **Не удалять том базы данных**.
3. Выполнить `docker compose up -d`, `npm ci`, `npx prisma generate`, `npm run db:migrate`, `npm run db:status`.
4. Запустить `npm run dev`. Проверить `/api/health`, `/account/security`, `/account/favorites`, `/admin/readiness`.
5. Настроить MFA персонала. После завершения можно выставить `ENFORCE_STAFF_MFA=true`, перезапустить процесс и перепроверить входы.
6. Сохранить безопасную копию `SESSION_SECRET`; потеря/ротация секрета без миграции приведёт к потере доступа к старым TOTP-ключам.

## Что остаётся до коммерческого запуска

Нужны реальный платёжный провайдер, проверка его событий и возвратов, email-подтверждение/восстановление, защита входа для персонала на открытом сервере, внешние логирование и мониторинг, устойчивое файловое хранилище, юридические документы и независимая проверка безопасности.

Не выставляйте `PUBLIC_INDEXING_ENABLED=true` до завершения этих работ. Индексация разрешается только по явному указанию HTTPS-домена.
