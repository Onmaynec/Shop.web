# StandoffShop — визуальная система v0.5.0

## Направление

Вся визуальная система построена вокруг монохромного интерфейса: глубокий чёрный фон, белая типографика, тонкие границы, минимальное количество декоративных элементов и свободное пространство.

За референс принята композиция современного сайта Next.js: компактная верхняя навигация, большая контурная надпись в первом экране, крупный заголовок и сдержанный контраст. Исходный HTML референса не копировался в магазин: структура и стили StandoffShop созданы отдельно.

## Цвета

| --- | --- |
| Фон | `#050505` |
| Карточки и формы | `#0D0D0D` |
| Поверхность при наведении | `#151515` |
| Линии | `#272727` |
| Основной текст | `#EDEDED` |
| Вторичный текст | `#898989` |

Оранжевые и золотые акценты старого интерфейса убраны. У статусов разные подписи и оттенки серого, чтобы их значение не зависело только от цвета.

## Типографика и сетка

- Стек шрифтов: `Inter` (при наличии), `Segoe UI`, системные sans-serif; нет внешней загрузки шрифтов.
- Крупные заголовки: плотный трекинг, высота строки близкая к 1.1.
- Подписи/метаданные: уменьшенный размер, моноширинный шрифт, разреженные буквы.
- Максимальная ширина контента: 1400 px; адаптация к планшетам и телефонам.
- Геометрия: радиусы 8–12 px, границы 1 px, умеренные тени только у интерактивных элементов.

## Общие элементы

- Хедер остаётся видимым при прокрутке; содержит навигацию, иконки аккаунта/корзины и открытие поиска.
- Поиск поддерживает `Ctrl+K` / `Cmd+K`, `Esc` и отправку запроса в каталог.
- Иконка корзины отображает количество позиций на основе локальной корзины.
- Футер: информация о проекте, ссылки и сведения о демонстрационном режиме.
- Кнопки: состояния по наведению/нажатию, клавиатурный focus, disabled.
- Формы: единый контраст, подсветка фокуса и текстовые сообщения об ошибках.
- Ошибки и пустые экраны: отдельные страницы 404, ошибки загрузки, skeleton при переходах.
- Админ-панель приведена к тем же цветам, компонентам, типографике и состояниям.

## Анимация

- Первая загрузка: плавное появление с небольшим смещением по Y.
- Карточки: умеренный подъём и изменение границы при наведении.
- Окно поиска и модальные формы: короткая анимация появления.
- Индикатор демо-режима и skeleton: мягкая периодическая анимация.
- При включённом `prefers-reduced-motion: reduce` отключаются длительные анимации и переходы.

Не используются тяжёлые видеофоны, бесконечный параллакс и обильное свечение. Переходы должны помогать пониманию интерфейса, а не мешать.

## Изображения для наполнения

Все ключевые страницы могут работать без внешних графических файлов. Если нужны изображения товаров или дополнительные акценты, подготовьте:

1. **Фотографии или иллюстрации конкретных товаров** — 1200×1200 px, WebP/PNG/JPEG, желательно однотипный ракурс и нейтральный фон. Добавляются по HTTPS-ссылке из админки.
2. **Логотип StandoffShop** — вектор SVG либо PNG с прозрачностью. Основной вариант светлый для чёрного фона и квадратная иконка.
3. **Дополнительный атмосферный баннер** — 2400×1200 px, преимущественно чёрный/серый, без встроенного текста, с свободным местом под заголовок.

Для текущего дизайна баннер не обязателен. При появлении качественных материалов их можно добавить без изменения платёжной или торговой логики.

## Контроль качества

После визуальных изменений необходимо проверить desktop 1440×900, tablet 768×1024, mobile 390×844 и малый mobile 320×700: меню, поиск, каталог, карточки товаров, корзину, форму авторизации и модальные окна админки. CI проверяет сборку и бизнес-логику, но не доказывает отсутствие всех визуальных дефектов. Для полной приёмки необходим ручной браузерный просмотр и визуальные e2e-снимки.
