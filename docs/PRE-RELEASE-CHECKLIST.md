# StandoffShop — контрольный список v0.9.0-rc.1

## Проверено автоматически

В GitHub Actions для предрелиза проверяются:
- Установка `npm ci` из зафиксированного lockfile;
- Проверка уязвимостей высокой серьёзности production-зависимостей;
- `prisma validate`, `prisma generate`, версионированные миграции и сравнение схемы с БД;
- TypeScript, Vitest, production-сборка Next.js;
- Проверки каталога, авторизации, заказов, административных API, политики Origin;
- Интеграция поддержки: роли, отзыв сессий, приватная переписка, назначение и закрытие обращений;
- Операционный CSV: права ADMIN, фильтрация и защита от формул;
- Локальный платёжный sandbox: проверка события оплаты/возврата и безопасного исполнения;
- Интеграция исполнителей: назначение задач, запрет чужих задач, приватная загрузка и запрет публикации;
- Браузерные скриншоты desktop/mobile для каталога, заказа, поддержки, персонала и отчётности.

## Перед локальным обновлением

1. Сохранить дамп PostgreSQL.
2. Сохранить папки `data/media` и `data/deliveries`, если они существуют.
3. Не выполнять `docker compose down -v`; сохранять старый каталог Docker Compose-проекта.
4. Скопировать исходники обновления и сохранить свой `.env` с существующими секретами.
5. Выполнить `npm ci`, `npx prisma generate`, `npm run db:migrate`, `npm run db:status`.
6. После запуска проверить `/api/health`, `/admin/staff`, `/support`, `/admin/operations`.
7. Назначать новые роли только проверенным аккаунтам. После смены роли требуется повторный вход.

## Блокеры стабильного коммерческого запуска

- **Платежи:** реальный провайдер отсутствует; нельзя принимать оплату или выдавать товары на основе клиентских ответов.
- **Идентификация:** нет подтверждения email, MFA и восстановительного потока для администраторов.
- **Инфраструктура:** не настроены production WAF, прокси-лимиты, автоматизированные резервные копии и мониторинг.
- **Файлы:** локальное хранилище требует постоянного тома, отдельного бэкапа и дополнительного сканирования.
- **Юридическая часть:** необходимо проверить правила Standoff 2, условия продажи услуг, возвраты, конфиденциальность и персональные данные.
- **Проверка перед публикацией:** нужен независимый security review, нагрузочные тесты и staging с отдельными секретами.

Не маркируйте эту версию как готовую к коммерческому использованию. GitHub Release должен иметь тип **Pre-release**.
