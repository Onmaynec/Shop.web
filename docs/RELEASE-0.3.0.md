# StandoffShop v0.3.0 — Admin & Catalog Management

Эта версия заменяет раннюю экспериментальную панель полноценным разделом управления магазином. Код расположен в ветке `main` репозитория `Onmaynec/Shop.web`.

## Интерфейс

- Отдельные разделы: обзор, товары, категории, заказы и покупатели.
- Единое боковое меню, мобильная адаптация, состояния пустых списков.
- Поиск и фильтры товаров, заказов и пользователей.
- Окна создания и редактирования с выводом ошибок.
- Обновлены главная страница, каталог, карточка товара, навигация и личный кабинет.

## Каталог

- Создание, редактирование и удаление пустой категории.
- Создание, редактирование, публикация, снятие с продажи товара.
- Изображение товара по прямой HTTPS-ссылке.
- Цены в БД хранятся в копейках.
- Сервер проверяет данные через Zod; при конфликте slug выдаёт корректную ошибку.
- Архивирование не удаляет товар, связанный с заказами.
- Постраничная выборка товаров и заказов.

## Заказы и аккаунты

- Детальная карточка заказа с позициями и зафиксированными ценами.
- Безопасные переходы статусов с атомарным условием текущего статуса.
- Ручная установка `PAID` запрещена.
- Просмотр покупателей без доступа к хешам паролей.
- В личном кабинете отображается текущая сессия, роль, история заказов и ссылка на управление магазином для ADMIN.

## Проверки

Добавлены тесты валидации и жизненного цикла заказа, GitHub Actions для Prisma/TypeScript/тестов/сборки. Исходники проекта проверяются CI на каждом push в main и pull request. Фактический результат последнего запуска следует смотреть на вкладке Actions.

## Локальные данные

Команда `npm run db:seed` создаёт пробную категорию и две позиции в статусе `DRAFT`. Реальные товары и продажи не симулируются автоматически.

## Установка

После скачивания актуальных исходников необходимо выполнить `npm install`, `npx prisma generate`, `npm run db:push`, затем `npm run dev`. В `.env` должны быть `DATABASE_URL` и собственный случайный `SESSION_SECRET`.

## Ограничения

Это версия для локального тестирования и дальнейшей разработки, а не production-релиз. Платежи, автоматическая выдача, промокоды, загрузка файлов, действия сотрудников, журнал аудита, rate limiting и e2e ещё не готовы. Товары в каталоге должны соответствовать условиям игры и правовым требованиям.
