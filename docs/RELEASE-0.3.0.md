# StandoffShop v0.3.0 — Admin & Catalog Management

## Реализовано
- Управление категориями: создание.
- Управление товарами: создание, редактирование, публикация, перевод в черновик и архив.
- Заказы: просмотр последних 100, состава заказа и email покупателя.
- Ограниченное изменение статуса заказа с серверными проверками переходов.
- Обновлённый интерфейс /admin; доступ только пользователям с ролью ADMIN.

## Ограничения
- Нет редактирования категорий, промокодов, загрузки изображений, управления персоналом, пагинации и аудита.
- Админ не может отметить заказ оплаченным: платежный провайдер не подключен.
- Нужны тесты, rate limiting и защита авторизации до production.
- После обновления необходимо выполнить npm install, npx prisma generate, npm run db:push и npm run dev.
- Это исходники в main, не подтверждённый production-релиз.
