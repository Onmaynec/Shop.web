# StandoffShop — план разработки

Название продукта: **StandoffShop**. Имя репозитория Shop.web не меняет название магазина.

## v0.1.0 — Foundation
- Next.js, TypeScript, PostgreSQL, Prisma
- Каталог, страницы товаров, серверная модель заказов
- Интерфейс платежного адаптера без подключения реального эквайринга
- Docker Compose и инструкция запуска

## v0.2.0 — Покупатель
- Корзина и оформление заказа
- Авторизация и история заказов
- Проверка цен и доступности на сервере
- Валидация полей и защита от повторного создания заказа

## v0.3.0 — Управление (частично реализовано)
- Админ-панель, роли, категории, товары, заказы, список покупателей
- Промокоды, аудит действий и поддержка покупателей отложены на будущие версии

## v0.4.0 — Платежная готовность (реализовано для локального тестирования)
- Абстракция платёжных провайдеров без реального эквайринга
- Подписанные webhook, идемпотентное оформление, полные тестовые возвраты
- Sandbox только для разработки и отдельный CI со сценариями жизненного цикла заказа

## v0.5.0 — Monochrome UI (реализовано)
- Полный монохромный редизайн главной, каталога, товаров, корзины, аккаунта и админки
- Единая адаптивная дизайн-система, состояния UI и анимации
- Поиск через Ctrl+K, мобильное меню, счётчик корзины, loading/error/404

## v0.6.0 — Усиление безопасности (следующий этап)
- Ограничение частоты запросов и защита от перебора паролей
- Аудит административных операций и событий оплаты
- Подтверждение email, восстановление доступа и защита персональных данных
- Миграции Prisma, мониторинг, обработка ошибок и дополнительное e2e-покрытие

## Перед публикацией
- Проверить разрешенность товаров и способов передачи по правилам Standoff 2
- Утвердить условия продажи цифровых товаров, возвратов и обработку персональных данных
- Подключить эквайринг силами владельца магазина
- Пройти тесты и проверку безопасности

Нельзя считать заказ оплаченным по ответу браузера: только после доверенного подтверждения провайдера.
